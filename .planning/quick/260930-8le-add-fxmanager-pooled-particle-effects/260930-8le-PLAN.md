<task type="auto">
  <name>Task 1: Create FxManager with pooled ParticleSystem playback</name>
  <files>Assets/Scripts/FxManager.cs</files>
  <action>
Create Assets/Scripts/FxManager.cs (global namespace, Allman braces, 4-space indent, `using System.Collections.Generic; using UnityEngine;`). Two classes in the file are acceptable (FxPoolItem is an internal helper).

class FxManager : MonoBehaviour:
- `[Header("Pooling")] public int defaultWarmCount = 0;` and an optional per-prefab warm list: `[System.Serializable] public class WarmEntry { public ParticleSystem prefab; public int count = 4; }` with `public List<WarmEntry> warm = new List<WarmEntry>();`.
- `private Dictionary<ParticleSystem, Queue<ParticleSystem>> pools` mirroring BulletManager's dictionary-of-queues.
- `void Awake()`: for each warm entry with non-null prefab and count > 0, call `Prewarm(entry.prefab, entry.count)`.
- `public void Prewarm(ParticleSystem prefab, int count)`: get-or-create pool queue; loop count times calling a private `Spawn(prefab)` and enqueue the result (instances are created stopped/idle).
- private `ParticleSystem Spawn(ParticleSystem prefab)`: `Instantiate(prefab, transform)`; get or add `FxPoolItem` on the instance root (`GetComponent` else `AddComponent`), set `item.manager = this; item.prefabKey = prefab;`. Set `var main = ps.main; main.stopAction = ParticleSystemStopAction.Callback;` on the ROOT system only (stop callback fires on the system whose stopAction is Callback, and for the root it fires once the root and its child systems are all finished; do not set it on children or the instance would be returned multiple times). Call `ps.Stop(true, ParticleSystemStopBehavior.StopEmittingAndClear)` so it starts idle. If `main.loop` is true, `Debug.LogWarning($"{name}: {prefab.name} is looping and will never return to the pool.", prefab)`.
- `public void Play(ParticleSystem prefab, Vector3 pos, Quaternion rot)`: return if prefab null; get-or-create the queue; dequeue until a non-null instance is found (skip destroyed entries), else `Spawn(prefab)`. Set `ps.transform.SetPositionAndRotation(pos, rot)`, then `ps.Clear(true)` THEN `ps.Play(true)` (per spec: Clear then Play, both with children).
- `public void Return(ParticleSystem ps, ParticleSystem key)`: if ps null return; if key non-null and pools has key, enqueue; else Destroy(ps.gameObject).
- Unpooled fallback helper for callers: `public static void PlayOrInstantiate(FxManager fx, ParticleSystem prefab, Vector3 pos, Quaternion rot)` -- if prefab null return; if fx != null `fx.Play(...)` else `Instantiate(prefab, pos, rot)`. This keeps the call sites to one line each and preserves the old behaviour in scenes without an FxManager.

class FxPoolItem : MonoBehaviour (same file): `[HideInInspector] public FxManager manager; [HideInInspector] public ParticleSystem prefabKey;` and `void OnParticleSystemStopped() { if (manager != null) manager.Return(GetComponent<ParticleSystem>(), prefabKey); }`. Add a comment explaining that this only fires because FxManager sets main.stopAction = Callback on the root system.

Comment the non-obvious ordering (Clear before Play so reused instances don't flash old particles; Callback only on the root).
