# Spec: mob aiming and firing through HandRig (agreed with user, 2026-10-01)

Builds on quick tasks 260930-x5h (per-hand ideal/real aim points) and 261001-14s (AimPart registry, owner-layer weights).

## Problem
MobBrain only paths. Mobs with a HandRig never aim: nothing moves their `HandRig.aimPoint`, `HandRig.lookSource` defaults to Camera.main (the PLAYER's camera, which would make mob cones follow the player's view), and `Move` only rotates the body while moving, so a stopped mob never turns to face its target.

## Decisions (LOCKED)
- All mob combat logic lives in `Assets/Objects/Units/MobBrain.cs` (new `[Header("Combat")]` tunables). Do NOT modify `Move.cs` (it has unrelated uncommitted user edits) or `PlayerManager.cs`. Small additive HandRig/Mob changes are allowed only if strictly required.
- Eye / look source: MobBrain has a public `Transform eye` (default: the mob's own transform when unset; prefer a head bone if assigned). In Start (after HandRig.Awake has defaulted to Camera.main), set `hands.lookSource = eye` so the mob's cone axis comes from its own eye.
- Aim point: if `hands.aimPoint` is null, MobBrain creates an unparented helper GameObject (named "<mob> AimPoint") and assigns it; destroy it in OnDestroy. Each Update while engaged, place it at the target's aim centre: the target's `Object` collider bounds centre (union of its non-trigger colliders, cached/refreshed cheaply) or, if none, `target.position + Vector3.up * aimHeight`. HandRig's cone search then picks the actual part (head/limbs) via the existing AimPart registry and ScorePart.
- Engage rules: engaged when an item is held that `usesAiming`, target is within `shootRange`, target's Object is not destroyed/dead, and line of sight from the eye to the aim centre is clear (raycast with a tunable `sightMask`, ignoring the mob's own colliders and the target's own colliders). While engaged: stop pathing when within `keepDistance` (else keep approaching), rotate the body's yaw toward the target at `turnSpeed` deg/s (via the Rigidbody's rotation / MoveRotation, only while Move has no move input so the two never fight), call `mob.Aim(true)`, and fire.
- Firing: per hand, mirror PlayerManager's routing (two-handed items only answer their defaultHand; use `Item.SlapTrigger(bool)`). Fire in bursts: hold the trigger for `burstDuration` seconds, release for `burstCooldown` seconds (random +/- `burstJitter`), and only press after the hand's aim has settled: wait `reactionTime` seconds after first becoming engaged. Release triggers immediately on disengage, death, or target loss.
- Disengage (out of range, no sight, target dead/null, mob dead): release triggers, `mob.Aim(false)`, resume pathing.
- Mob accuracy is tuned only through the existing item fields (swayRadius, onTargetAccuracy, offTargetLooseness, idealFollowSpeed); no new accuracy system.
- Existing `TODO(human)` in MobBrain.CombineSteering stays untouched. Add NO new TODO(human) markers anywhere.
