  <name>Task 2: FixedUpdate force model (suspension, grip, drive, friction cone) and upright/yaw torque</name>
  <files>Assets/Procedural/Animation/LegSolver.cs</files>
  <action>
Add `void FixedUpdate()` (allocation-free; only for-loops over legSet, no LINQ, no new arrays/lists) that calls, in order: UpdateStepping(dt) (Task 3 implements it; declare the call now and define a stub-free method in Task 3 — to keep the file coherent, Task 2 and 3 are written into the same file before verification), then ApplyLegForces(), then ApplyUprightAndYaw().

ApplyLegForces:
1. First pass: count plantedCount = legs with planted && hipSocket != null; accumulate avgGroundNormal (normalized sum, fallback Vector3.up). If plantedCount == 0 return (airborne, no force).
2. Heading: desired horizontal velocity = targetVelocity. If its magnitude < 0.01, heading = zero (no drive; lateral grip then acts to cancel all horizontal slip = braking). Else heading = targetVelocity.normalized.
3. Second pass per planted leg: socket = hipSocket.position; v = hip.GetPointVelocity(socket); raycast from socket along -n_prev (use stored groundNormal, falling back to Vector3.down) with range maxLength + probeDistance via ProbeGround. If no hit: planted = false, gripUsage = 0, continue (treated as airborne/swinging). Otherwise update groundNormal = hit.normal and L = hit.distance, store lastLength; do NOT move plantPoint from this hit (plantPoint is the pinned foot; only use the hit for L and normal).
4. Mass scaling: massScale = hip.mass / plantedCount.
5. Suspension: Fs = max(0, (springK * (restLength - L) - damperC * Vector3.Dot(v, n)) * massScale) applied along n. Comment why: feet push, never pull.
6. Lateral grip: slip = v projected on plane(n); if heading != zero, remove the component of slip along heading that we want (desired slip velocity = heading * maxSpeed magnitude of targetVelocity), i.e. lateral part = slip minus its projection on heading; F_lat = -lateral * lateralGrip * massScale. If heading is zero, F_lat = -slip * lateralGrip * massScale.
7. Drive: if heading != zero, F_drive = Vector3.ProjectOnPlane(targetVelocity - v, n) projected onto heading, times driveGain * massScale (push toward targetVelocity along heading).
8. Friction cone: F_tan = F_lat + F_drive; limit = friction mu * Fs; if limit <= 1e-4 then F_tan = zero and gripUsage = (F_tan requested > 0 ? 1 : 0) else gripUsage = F_tan.magnitude / limit and if gripUsage > 1 scale F_tan by 1/gripUsage. Store leg.gripUsage (the requested/limit value, unclamped, so stepping can react to saturation).
9. F = n * Fs + F_tan; leg.lastForce = F; hip.AddForceAtPosition(F, socket, ForceMode.Force).

ApplyUprightAndYaw: upAxis = useAverageGroundNormal && plantedCount > 0 ? avgGroundNormal : Vector3.up. Torque axis = Vector3.Cross(hip.transform.up, upAxis) (magnitude ~ sin angle); tilt torque = axis * uprightK - hip.angularVelocity's component perpendicular to up * uprightD... Use: torque = axis * uprightK - hip.angularVelocity * uprightD, scaled by hip.mass. Yaw (only when targetVelocity horizontal magnitude > 0.1 and plantedCount > 0): desiredFwd = Vector3.ProjectOnPlane(targetVelocity, upAxis).normalized; yawErr = Vector3.SignedAngle(Vector3.ProjectOnPlane(hip.transform.forward, upAxis), desiredFwd, upAxis) * Mathf.Deg2Rad; add upAxis * (yawErr * yawK - Vector3.Dot(hip.angularVelocity, upAxis) * yawD) * hip.mass. Apply with hip.AddTorque(t, ForceMode.Force). Guard tilt/yaw with plantedCount > 0 so an airborne body is not torqued. Comment that hip.mass scaling keeps gains mass-independent (same intent as Move.cs using ForceMode.Acceleration).
