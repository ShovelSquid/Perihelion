Choices made at Claude's discretion (the SPEC does not fix these):
- Armor is a flat per-hit reduction, floored at 0.
- The score is a cost (lower wins), so the user's own example `angleOffCentre / aimWeight` drops straight in, and "beat by 20%" means challenger < current * (1 - stickiness).

- The look-drag tunables are removed, because the anchor easing at idealFollowSpeed now supplies the trailing.
- `offsetDampingRatio`'s code default drops to 0.5 so new rigs overshoot. Existing scene values must be lowered by the user in the inspector.
