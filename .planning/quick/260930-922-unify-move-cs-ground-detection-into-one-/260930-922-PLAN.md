<task type="auto">
  <name>Task 1: Add ground-check state, tunables and UpdateGroundState/OnLand</name>
  <files>Assets/Objects/Units/Move.cs</files>
  <action>
In the existing `[Header("Ground Check")]` group, keep `groundLayer`, `groundCheckDistance` and `fallSpeed`. Add these public fields with defaults:
- `groundProbeRadius = 0.9f`. It is a fraction of the collider's horizontal radius, taken as min(bounds.extents.x, bounds.extents.z), with a [Range(0.1f, 1f)] attribute.
- `groundProbeSkin = 0.05f`. This is how far inside the collider bottom the sphere starts.
- `jumpGroundLockout = 0.1f`.

Add private state:
- `float jumpLockUntil`.
- `Vector3 lastGroundNormal = Vector3.up`.

Add `private void UpdateGroundState()`. It is the only place inAir is computed. Steps:
1. Contact term: `bool contact = grounded && groundNormal.y > 0.5f`. `grounded` is the flag OnCollisionStay set in the previous physics step.
2. Probe term:
   - Bounds b = moveCollider.bounds.
   - r = groundProbeRadius * Mathf.Min(b.extents.x, b.extents.z).
   - origin = new Vector3(b.center.x, b.center.y - b.extents.y + r + groundProbeSkin, b.center.z). The sphere bottom then sits groundProbeSkin above the collider bottom, so it starts inside the collider and does not depend on the transform pivot.
   - `Physics.SphereCast(origin, r, Vector3.down, out RaycastHit hit, groundCheckDistance + groundProbeSkin, groundLayer, QueryTriggerInteraction.Ignore)`.
   - Count the probe as ground only if `hit.normal.y > 0.5f`.
   - Comment that the mob's own collider is ignored because the cast starts inside it.
3. `bool nowGrounded = Time.time >= jumpLockUntil && (contact || probeHit)`. While the lockout is active, report airborne.
4. `lastGroundNormal` is `groundNormal` when contact is true, else the probe hit normal. Update it only when nowGrounded.
5. Compare with the previous `inAir`:
   - Set `bool wasAir = inAir; inAir = !nowGrounded;`.
   - If `wasAir != inAir`, call `mob.anim.SetBool("inAir", inAir)`. Write only on change.
   - If `wasAir && !inAir`, call `OnLand()`.
   - The grounded-to-airborne transition needs nothing else.

Add `private void OnLand()`, with a comment that it is the single landing handler:
- Always, at the end: `airJumps = maxAirJumps;` and `fallSpeed = 0f;` (this fixes the stale-fall-damage bug).
- If `!mob.dead`, in this order:
  - `mob.anim.SetTrigger("Land")`.
  - `PlayLandingSound()`.
  - The existing groundJumpParticle block, moved verbatim (rotation from linearVelocity and transform.up, plain Instantiate at jumpFXPoint). Do not pool it.
  - Capture fall damage before resetting: `if (fallSpeed > mob.fallDamageSpeedMin) mob.FallDamage(fallSpeed, lastGroundNormal.y);`. This keeps the current rule and now uses the ground normal. Remove the "fix this to be aligned with the normal later" comment.
- When dead, skip the fx and damage but still do the resets. State is kept fresh so a respawn does not fire a spurious landing.

Make `public void InAir()` a thin wrapper that calls `UpdateGroundState()`. Update its old body accordingly (it no longer does the Raycast).

Decision on dead: the check runs for dead mobs too, at the top of FixedUpdate before the dead branch. Justification: a ragdolling corpse keeps inAir, the anim bool and fallSpeed correct. Without it, respawning would leave stale airborne state and trigger a bogus landing with old fallSpeed. Side effects are gated by `!mob.dead` in OnLand.
