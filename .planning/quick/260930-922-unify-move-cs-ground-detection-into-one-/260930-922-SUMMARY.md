# Quick 260930-922: Unify Move.cs ground detection

Move.cs now computes inAir in one place, `UpdateGroundState()`, called first in every FixedUpdate
(contacts from OnCollisionStay plus a bounds-derived SphereCast, with a post-jump lockout).
Landing is handled solely in `OnLand()`, which also resets fallSpeed (fixes stale fall damage).
Jump() uses cached state and `jumpLockUntil`; OnCollisionEnter/Exit and DelayAction were removed.
Public API (`inAir`, `InAir()`, `fallSpeed`) and serialized field names are preserved.

**Verification:** Unity was not available. Nothing was compiled or run. Checks were by reading and grep only
(removals confirmed, ChargeJump.cs and CameraController.cs still reference the kept public fields,
no TODO(human) added, only Move.cs changed).
