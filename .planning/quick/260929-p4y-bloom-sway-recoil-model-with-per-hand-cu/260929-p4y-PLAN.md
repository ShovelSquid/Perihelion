<objective>
Replace the fixed-kick, underdamped recoil spring with a per-hand angular model:
- **Bloom:** a spread radius that grows with each shot and recovers over time.
- **Sway:** a smooth noise target that wanders inside the bloom circle.
- **Aim offset:** a critically damped spring that chases the sway target and is kicked by each shot along the gun's own up.

The aim solver works backwards from the aim point rotated by that offset. Bullets leave along the real muzzle forward, so where the gun points is where the shot goes. A four-prong cursor per hand, on the new ScreenAnchor, shows the actual muzzle hit point and the current bloom.

Purpose: recoil and inaccuracy become one readable, per-hand state that drives the pose, the bullets and the cursor together. Randomness is no longer rolled per bullet where the player can't see it.
Output: reworked `Assets/Scripts/HandRig.cs` and `Assets/Scripts/Gun.cs`, new `Assets/Scripts/AimCursor.cs`, and a SUMMARY with the in-editor cursor setup and tuning notes.
